This is a very large project (a CEFR A0–A1 multilingual verb database for English, French, Italian, Russian, Greek, with prepositions where applicable). A true executive list will probably contain ~1,000–2,000 core verb units, not 10,000, because A0–A1 learners do not need 10,000 verbs. Adding more would mostly introduce A2–C2 vocabulary and reduce pedagogical value.

A good COSYlanguages-style structure would be:

Field	Example
CEFR level	A0–A1
Concept	movement / communication / daily life
English	go
Pattern	go to + place / go for + activity
French	aller
Pattern	aller à + lieu / aller faire + infinitif
Italian	andare
Pattern	andare a + luogo / andare a + infinitive
Russian	идти / ходить
Pattern	идти в + accusative / ходить по + dative
Greek	πηγαίνω
Pattern	πηγαίνω σε + place
Examples	basic A0–A1 sentences

I suggest creating it in macro-domains, because this will connect directly to your COSY curriculum.
