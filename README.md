# COSYtools

COSYtools is a suite of client-side language reference tools, verb conjugators, noun gender checkers, case declension tables, and interactive grammar practice exercises supporting 14 languages. Visit the live site at [https://cosylanguages.github.io/COSYtools/](https://cosylanguages.github.io/COSYtools/) or explore the main platform at [https://cosylanguages.github.io/COSYlanguages/](https://cosylanguages.github.io/COSYlanguages/).
